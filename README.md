이 저장소는 한빛아카데미에서 출간된 「IT CookBook, 파이토치로 배우는 현대 인공지능」의 실습 코드를 제공합니다.

이 책은 파이썬과 PyTorch의 기초부터 CNN, RNN, 트랜스포머, 대규모 언어 모델, 확산 모델, 강화학습, 프롬프트 엔지니어링, 언어 모델 정렬, MCTS, RAG 기반 AI 서비스 구현까지 현대 인공지능의 주요 기술을 단계적으로 다룹니다.

책의 설명을 먼저 읽은 뒤 해당 절의 실습 코드를 실행하면, 인공지능 모델의 원리가 실제 코드에서 어떻게 구현되는지 순서대로 확인할 수 있습니다.

## GPU 사용 확인

PyTorch가 NVIDIA GPU를 인식하는지 확인하려면 다음 코드를 실행합니다.

```python
import torch

print("PyTorch version:", torch.__version__)
print("CUDA available:", torch.cuda.is_available())

if torch.cuda.is_available():
    print("GPU:", torch.cuda.get_device_name(0))
```

Apple Silicon Mac에서는 다음 코드로 MPS 사용 가능 여부를 확인할 수 있습니다.

```python
import torch

print("MPS available:", torch.backends.mps.is_available())
print("MPS built:", torch.backends.mps.is_built())
```

CUDA, MPS, CPU 가운데 사용할 수 있는 장치를 자동으로 선택하려면 다음과 같이 작성할 수 있습니다.

```python
import torch

if torch.cuda.is_available():
    device = torch.device("cuda")
elif torch.backends.mps.is_available():
    device = torch.device("mps")
else:
    device = torch.device("cpu")

print("사용 장치:", device)
```

일부 연산은 MPS에서 지원되지 않을 수 있습니다. 이 경우 CPU를 사용하거나 Google Colab의 CUDA GPU 환경에서 실행하세요.

처음 실행할 때는 다운로드 때문에 시간이 오래 걸릴 수 있습니다. 두 번째 실행부터는 로컬 캐시에 저장된 파일을 사용하므로 일반적으로 더 빠르게 시작됩니다.

학교나 기관의 네트워크에서 외부 접속을 제한하면 모델과 데이터셋 다운로드가 실패할 수 있습니다.

## Hugging Face 모델 사용

일부 모델은 Hugging Face 계정 로그인이나 모델 사용 약관 동의가 필요할 수 있습니다.

Hugging Face CLI를 설치하고 로그인하려면 다음 명령을 실행합니다.

```bash
pip install huggingface_hub
huggingface-cli login
```

명령을 실행한 뒤 Hugging Face에서 발급받은 액세스 토큰을 입력합니다.

공개 모델은 로그인 없이 사용할 수 있는 경우도 있지만, 모델마다 이용 조건이 다르므로 해당 모델 페이지의 라이선스와 접근 조건을 확인하세요.

## 서비스 실행

17장의 FastAPI 예제를 실행할 때는 예제 코드의 파일명과 FastAPI 객체 이름에 맞춰 다음과 같은 명령을 사용할 수 있습니다.

```bash
uvicorn app:app --reload
```

서버가 정상적으로 실행되면 일반적으로 다음 주소에서 접속할 수 있습니다.

```text
http://127.0.0.1:8000
```

Gradio 예제는 해당 파이썬 파일을 실행하면 터미널에 접속 주소가 표시됩니다.

```bash
python 17_3.py
```

로컬 서버가 시작되지 않으면 다음 사항을 확인하세요.

- 같은 포트를 다른 프로그램이 사용하고 있는지
- 방화벽이나 보안 프로그램이 접속을 차단하는지
- 필요한 패키지가 모두 설치되어 있는지
- 현재 터미널에서 올바른 가상 환경이 활성화되어 있는지

## 실행 시 유의사항

- 주피터 노트북의 셀은 위에서 아래로 순서대로 실행하세요.
- 런타임을 다시 시작하면 기존 변수와 메모리에 저장된 모델이 사라집니다.
- 일부 코드는 실행 중 모델 가중치나 데이터셋을 인터넷에서 다운로드합니다.
- 처음 모델을 불러올 때는 다운로드와 초기화에 시간이 걸릴 수 있습니다.
- GPU 메모리가 부족하면 배치 크기, 입력 크기, 생성 이미지 크기, 최대 토큰 수를 줄이세요.
- 대형 모델 실습은 더 작은 모델로 변경해 실행 구조를 먼저 확인할 수 있습니다.
- 강화학습은 무작위 초기값과 환경 변화 때문에 실행할 때마다 결과가 달라질 수 있습니다.
- 이미지와 텍스트 생성 결과도 난수 시드와 모델 버전에 따라 달라질 수 있습니다.
- 라이브러리 버전이 달라지면 함수 이름이나 인자가 바뀔 수 있습니다.
- 서비스 예제는 로컬 포트를 사용하므로 실행 전에 해당 포트가 비어 있는지 확인하세요.
- 외부 모델과 데이터셋을 사용할 때는 각각의 라이선스와 이용 조건을 확인하세요.

## 문제 해결

### `ModuleNotFoundError`가 발생하는 경우

오류 메시지에 표시된 패키지가 현재 파이썬 환경에 설치되어 있는지 확인합니다.

```bash
pip install 패키지이름
```

주피터 노트북을 사용한다면 노트북 커널과 터미널의 가상 환경이 서로 다를 수 있습니다.

현재 노트북이 사용하는 파이썬 경로는 다음 코드로 확인할 수 있습니다.

```python
import sys

print(sys.executable)
```

### CUDA 메모리 부족 오류가 발생하는 경우

다음 값을 줄여 보세요.

- 배치 크기
- 이미지 해상도
- 입력 문장의 길이
- 생성할 최대 토큰 수
- 동시에 처리하는 데이터 수

사용하지 않는 GPU 메모리를 정리하려면 다음 코드를 실행할 수 있습니다.

```python
import gc
import torch

gc.collect()

if torch.cuda.is_available():
    torch.cuda.empty_cache()
```

### 모델 다운로드에 실패하는 경우

다음 사항을 확인하세요.

- 인터넷 연결 상태
- Hugging Face 로그인 여부
- 모델 사용 약관 동의 여부
- 저장 공간 부족 여부
- 학교나 기관 네트워크의 외부 접속 제한 여부

### 실행 결과가 책과 다른 경우

다음 조건이 다르면 실행 결과도 달라질 수 있습니다.

- Python 버전
- PyTorch와 관련 라이브러리의 버전
- 사용한 CPU 또는 GPU
- 난수 시드
- 데이터셋 버전
- 사전 학습 모델 버전
- 모델 다운로드 시점

결과의 숫자가 책과 완전히 같지 않더라도 학습 과정과 전체 동작이 정상이라면 코드가 잘못된 것은 아닐 수 있습니다.
