# 파이토치로 배우는 현대 인공지능

이 저장소는 책 **「파이토치로 배우는 현대 인공지능」**의 실습 코드를 제공합니다.  
코드는 책의 절 단위로 구성되어 있으며, 앞 절의 내용을 이해하고 실행한 뒤 다음 절의 코드를 실행하면 학습 흐름을 따라가기 쉽습니다.

## 학습 자료 다운로드

이 책의 예제 코드는 이 저장소에서 다운로드할 수 있습니다.

1. 저장소 상단의 **Code** 버튼을 클릭합니다.
2. **Download ZIP**을 선택해 전체 소스 코드를 내려받습니다.
3. 압축을 해제한 뒤 원하는 장의 `.ipynb` 또는 `.py` 파일을 실행합니다.

주피터 노트북(`.ipynb`) 파일에는 코드와 실행 흐름이 함께 들어 있으므로, 처음 학습할 때는 노트북으로 실행하는 것을 권장합니다. 파이썬 스크립트(`.py`) 파일은 예제 코드를 빠르게 확인하거나 별도 환경에서 실행할 때 사용할 수 있습니다.

## 실행 환경

기본 예제는 Python과 PyTorch 환경에서 실행됩니다.

```bash
pip install torch numpy matplotlib
```

일부 장에서는 다음과 같은 추가 라이브러리가 필요합니다.

```bash
pip install torchvision transformers datasets peft trl diffusers accelerate
pip install gymnasium ultralytics pillow requests
pip install llama-index llama-index-embeddings-huggingface openai-whisper gtts pydub
pip install fastapi uvicorn python-multipart gradio
```

GPU가 있으면 CUDA 환경에서 더 빠르게 실행할 수 있습니다. 대형 언어 모델, 이미지 생성, 음성 처리, 강화학습 예제는 실행 시간이 길거나 외부 모델 다운로드가 필요할 수 있으므로 Google Colab 또는 GPU 환경 사용을 권장합니다.

## 파일 구성

파일명은 `장_절` 형식으로 구성되어 있습니다.

| 파일 | 주요 내용 |
| --- | --- |
| `1_2.ipynb`, `1_3.py`, `1_7.*` | 개발 환경, NumPy, PyTorch 텐서, 연산 장치, 시각화 |
| `2_3.*`, `2_7.*` | 선형 분류, K-means, 단일 뉴런 학습, 학습률과 손실 표면 |
| `3_4.*` | Dataset, DataLoader, 이진 분류 모델 학습 |
| `4_3.*`, `4_4.*` | CNN 기반 MNIST 분류, LSTM 시계열 예측 |
| `5_3.*`, `5_4.*`, `5_6.*` | YOLO 객체 탐지, U-Net 이미지 분할, 어텐션 기반 번역 |
| `6_5.*` | GAN 생성자와 판별자 학습 |
| `7_4.*` | 트랜스포머 어텐션, 인코더, 디코더 구현 |
| `8_4.*` | GPT-2 기반 텍스트 생성 |
| `9_4.*` | Stable Diffusion 기반 이미지 생성 |
| `10_5.*` | GPT-2 LoRA 파인튜닝 |
| `11_4.*`, `11_7.*` | Gymnasium 환경, DQN 강화학습 |
| `12_3.*`, `12_7.*` | REINFORCE, PPO 강화학습 |
| `13_3.*` | Qwen 모델 기반 프롬프팅과 CoT |
| `14_3.*` | DPO 기반 선호 학습 |
| `15_4.*` | 오목 환경, 정책-가치 네트워크, MCTS |
| `16_3.*` | RAG, Whisper, gTTS 기반 개인화 음성 어시스턴트 |
| `17_3.*` | FastAPI와 Gradio를 활용한 서비스 배포 예제 |

`*` 표시는 같은 번호의 `.ipynb`와 `.py` 파일이 함께 제공된다는 의미입니다.

## 실행 방법
